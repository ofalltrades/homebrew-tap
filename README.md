# Homebrew tap for Jaketts

Jaketts is a local text-to-speech CLI and desktop app powered by Kokoro-82M.

## Install

Apple Silicon Mac running macOS 14 Sonoma or newer:

    brew install ofalltrades/tap/jaketts

## Use

Speak text:

    jtts "Hello from Jaketts"

Launch the desktop GUI:

    jtts

Show the installed version:

    jtts -v
